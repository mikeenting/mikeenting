## Local preview and validation

This is a dependency-free static site. From the repository root, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Run `python3 scripts/validate_site.py` to check the page structure and local links, stylesheets, scripts, and assets. The same check runs in GitHub Actions on pushes and pull requests.

## Deployment and maintenance

The site is intended to be published from the repository root on the `main` branch with GitHub Pages; `CNAME` configures the custom domain. Keep the role, experience summary, and work history aligned across this README, `index.html`, `resume.html`, and `timeline.js`. Replace the résumé PDF in `assets/` when updating the résumé, and review the Google Analytics ID and the existing Content Security Policy together if analytics or third-party resources change.
